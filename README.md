# الكوتش (Alcoach)

تطبيق دور حلاقة لايف — نسخة أولى MVP. عربي RTL، موبايل فرست، وقابل للتثبيت كتطبيق (PWA).

## الفكرة

- الحلاق يسجّل حضوره لما يفتح المحل. لو مش مسجل حضور، مش بيظهر للزبائن ومش بيستقبل دور.
- الزبون يشوف الحلاقين الموجودين دلوقتي، يختار حلاقه، يختار الخدمة، وياخد رقم في الدور.
- الزبون يتابع مكانه لايف: قدامه كام واحد والانتظار التقريبي كام دقيقة.
- الحلاق عنده لوحة: يندّه على اللي بعده، يخلّص، أو يشيل حد من الدور. الزبون لما ييجي عليه الدور تظهرله "دورك!".
- دور واحد نشط للزبون في نفس الوقت، ومفيش ازدواج: الدور ماشي بالترتيب زي الكشك.

## التشغيل

```bash
node --no-warnings server.js
```

يحتاج Node 22.5 أو أحدث. مفيش أي مكتبات خارجية. قاعدة البيانات SQLite بتتعمل لوحدها في `dawrak.sqlite`. البورت 3000 (أو `PORT=8080`).

## التثبيت كتطبيق

افتح الموقع من الموبايل واضغط "ثبّت التطبيق". التثبيت الحقيقي يحتاج الموقع مرفوع على HTTPS.

## الحسابات

- التسجيل برقم الموبايل وكلمة سر، والمستخدم يختار: حلاق أو زبون.
- كلمات السر متخزنة scrypt hash، والجلسات بكوكي HttpOnly.

## ملحوظات النسخة الأولى

- كل حلاق مستقل بحسابه. مفيش لسه مفهوم "محل فيه كذا حلاق" أو صاحب محل يدير الكل.
- التحديث اللحظي بإعادة تحميل الصفحة كل 8 ثواني (بسيط وثابت). ترقية لاحقًا: WebSocket/SSE.
- مفيش إشعارات بصوت أو SMS لما الدور يقرب.
- التقدير الزمني = عدد اللي قدامك × متوسط وقت الحلاقة اللي الحلاق محدده عند تسجيل الحضور.
